What is this building made of?

Predict the structural system of individual buildings (adobe, reinforced concrete, masonry, steel) from their footprint, their neighbors and a few low-cost attributes.

How it works

From a footprint file and a field survey to a prediction for every building.

01

Split

Computes shape features from the footprints and splits the surveyed buildings by blocks, so neighbors never leak between train and test.

mlss split
02

Train

Five models, each with a cross-validated search over hyperparameters and imbalance strategies, plus a tuned decision rule for rare classes.

mlss train
03

Assess

Macro F1, Cohen's κ, confidence intervals, agreement between models and feature importance, all on held-out blocks.

mlss report
04

Predict

Apply the trained models to any buildings, surveyed or not, and get one class per model.

predict()
05

Check labels

Flag surveyed buildings that the models contradict, and review them on an interactive map.

mlss sanity

Use it

1. Install

git clone https://github.com/GeomaticsCaminosUPM/ml_structural_system.git
cd ml_structural_system
uv sync

2. Run an experiment

mlss split      --config config.yaml
mlss preprocess --config config.yaml
mlss report     --config config.yaml

3. Predict new buildings

from ml_structural_system.predict import predict

buildings = predict("config.yaml", "new_area.gpkg")
# one pred_<model> column per model

4. Check the labels

uv sync --extra sanity
mlss sanity --config config.yaml --data survey.gpkg
