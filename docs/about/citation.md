# Citation

If you use this package, please cite the paper:

> Sempere-Hernández, J., Ureña-Pliego, M., González-Rodrigo, B., Moya, B., Rodríguez, S., Chinesta, F., Marchamalo-Sacristán, M. *Estimating building structural systems from footprints: transferability of machine learning models across three Latin American cities.* In review.

The full reference will be added here once it is published.

The footprint features come from [footprint_attributes](https://github.com/GeomaticsCaminosUPM/footprint_attributes), described in:

> Ureña-Pliego, M., Rodríguez-Saiz, J., Núñez-Álvarez, G., Marchamalo-Sacristán, M., González-Rodrigo, B. (2026). A methodology for the automated estimation of footprint-derived seismic behaviour modifiers in building exposure assessment. *Advanced Modeling and Simulation in Engineering Sciences*, 13, 3. [doi:10.1186/s40323-026-00323-y](https://doi.org/10.1186/s40323-026-00323-y)
